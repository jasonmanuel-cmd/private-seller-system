## Mailing Instructions

**How to get addresses FREE:**
- Assessor Parcel Search → copy mailing address
- PropStream free trial → export 100 absentee high equity → has mailing address
- Tax-defaulted PDF → has APN → Assessor → mailing address

**How to send cheap:**
- Handwrite 20/week yourself (highest response)
- Or use Ballpoint mail service (uses real pen robot) — $2.25/letter — still looks handwritten
- Or use DocuPost $0.80/letter if typed (lower response but cheaper)

**Tracking:**
- Use different Google Voice numbers for each list to track which list calls (free Google Voice)
- Or ask: "How did you hear about private program?" and log in Sheet

- If no call in 14 days, send second letter (different color paper): "Hi [Name], just following up on my note about 123 Main — still open to private conversation? — Nathanael (661) 472-7499"
- Response doubles with 2nd letter

**Expected:**
- 100 letters → 2-5 calls → 1-2 appointments → 0.5-1 private listing
- Each private listing = $8k-15k commission, no competition
