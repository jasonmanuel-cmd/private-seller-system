# Target Lists for Private Sellers — How to Build for $0

## The 8 Lists That Produce Private Sellers (Ranked by Deal Quality)

### 1. Absentee Owners with High Equity (TIRED LANDLORDS) — #1 BEST
**Profile:** Owns house in Bakersfield/Tehachapi, lives in LA or out of state, owned 10+ years, 50%+ equity
**Why private:** Tired of managing from distance, bad tenants, wants quiet exit
**How to build FREE:**
- Go to https://assessor.kerncounty.com/parcel-search/ → Search by street (e.g., "Main St, Bakersfield") → Look at results → Mailing address different from property address + Last sale date <2015 = absentee high equity
- Build 20/day manually = 100/week free
- Or PropStream free trial: Filter Kern County, Absentee = Yes, Equity 50%+, Owned 10+ years, Property Type Single Family → Export

**What to send:** Letter #1 (Absentee)

### 2. Senior Owners 70+ Owned 20+ Years
**Profile:** Age 70+, owned 20+ years, house may need work, maybe moving to assisted living
**Why private:** Family doesn't want cleanout, showings
**How FREE:** Assessor → get owner name → TruePeopleSearch.com → shows age 70+ → add to list
**Letter #2**

### 3. Pre-Foreclosure NOD Last 90 Days
**Profile:** Received Notice of Default, 90 days to sell before auction, wants privacy
**Why private:** Doesn't want neighbors seeing auction sign
**How FREE:** https://recorder.kerncounty.com → Official Records Search → Doc Type: NOTICE OF DEFAULT → Date: Last 90 days → Get APN → Assessor → owner name → TruePeopleSearch phone
**Letter #3**

### 4. Tax-Delinquent 3-5 Years
**Profile:** Hasn't paid taxes 3-5 years, going to auction
**How FREE:** https://www.kcttc.co.kern.ca.us/tax-defaulted-property-sales/ → Download PDF → APN → Assessor → owner
**Letter #3 variant**

### 5. Probate / Inherited Vacant
**Profile:** Owner died, heir out of state, house vacant, full of stuff
**How FREE:** https://www.kern.courts.ca.gov → Case Search → Probate → Filed last 90 days → Decedent name → Assessor search decedent name → find property → heir name from case → TruePeopleSearch heir phone
**Letter #2 variant**

### 6. Code Violations / Vacant / Nuisance
**Profile:** House with open code case: overgrown, abandoned, substandard
**How FREE:** https://data.bakersfieldcity.us → Search Code Enforcement → Download CSV → filter residential vacant
**Letter #4**

### 7. Divorce Filings (Sensitive)
**Profile:** Filed divorce last 90 days, owns house together
**How FREE:** https://www.kern.courts.ca.gov → Case Search → Family Law → Divorce → Filed last 90 days → Parties → cross-ref Assessor for property owned
**Letter #5 — use carefully, or better target via Facebook ads not mail**

### 8. Expired FSBO / Old Expired Listings (If you want slight MLS touch)
**Profile:** Tried to sell FSBO or expired off MLS 6 months ago, still owns
**How FREE:** Zillow FSBO history, Craigslist old posts, or MLS expired search if you have access (but you said no MLS — so use Zillow)
**Letter #1 variant**

## How to Build List Manually for $0 (Step-by-Step)

**Example: Build 50 Absentee Tired Landlords in Bakersfield 93308 in 1 hour:**

1. Go to Assessor Parcel Search
2. Search City: Bakersfield, Street: "Calloway" (pick a street with rentals)
3. Open 20 parcels in new tabs
4. For each:
   - Property Address: 123 Calloway Dr, Bakersfield, CA 93308
   - Owner Name: John Smith
   - Mailing Address: 456 Main St, Los Angeles, CA 90001 → DIFFERENT = absentee
   - Last Sale Date: 2008 → owned 18 years = high equity
   - Add to Google Sheet: Address, Owner, Mailing Address, Phone (leave blank for now), Motivation: Tired Landlord, Deal Score 8
5. After 50, go to TruePeopleSearch.com, search owner name + mailing city, get phone free
6. You now have 50 private seller leads for $0

**Time:** 1 hour for 50 leads
